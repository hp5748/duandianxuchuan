# 接口规范

## REST API

### 下载接口

**端点**：`GET /api/proxy/download`

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| url | String | 是 | 目标文件路径（URL 编码），支持三种类型：<br>- 远程 URL：`https://example.com/file.zip`<br>- 本地路径：`C:\Users\Admin\Desktop\file.exe` 或 `/home/user/file.zip`<br>- UNC 路径：`\\server\share\file.txt` |

**请求头**：

| Header | 说明 | 示例 |
|--------|------|------|
| Range | 断点续传范围（可选） | bytes=1024- |

**响应头**：

| Header | 说明 |
|--------|------|
| Content-Type | 文件 MIME 类型 |
| Content-Length | 响应体大小 |
| Accept-Ranges | bytes（表示支持断点续传） |
| Content-Range | 部分内容范围（仅 206 响应） |
| Content-Disposition | 文件名 |

**响应状态码**：

| 状态码 | 说明 |
|--------|------|
| 200 | 完整下载成功 |
| 206 | 断点续传成功 |
| 400 | URL/路径格式非法 |
| 403 | 域名不在白名单（仅远程 URL） |
| 404 | 本地文件不存在 |
| 413 | 文件过大 |
| 416 | Range 无效 |
| 502 | 上游服务器错误（仅远程 URL） |

**错误响应格式**：

```json
{
  "code": 400,
  "message": "URL 格式非法",
  "timestamp": "2026-03-25T10:30:00Z"
}
```

## 请求示例

### 远程 URL 下载

```bash
curl -X GET "http://localhost:8080/api/proxy/download?url=https://example.com/file.zip" \
  -o file.zip
```

### 本地文件下载

```bash
# Windows 本地路径
curl -X GET "http://localhost:8080/api/proxy/download?url=C%3A%5CUsers%5CAdmin%5CDesktop%5Cfile.exe" \
  -o file.exe

# Linux 本地路径
curl -X GET "http://localhost:8080/api/proxy/download?url=%2Fhome%2Fuser%2Ffiles%2Ffile.zip" \
  -o file.zip
```

### UNC 网络路径下载

```bash
curl -X GET "http://localhost:8080/api/proxy/download?url=%5C%5C10.220.9.110%5Cshare%5Cfile.txt" \
  -o file.txt
```

### 断点续传

```bash
# 从第 1024 字节开始下载
curl -X GET "http://localhost:8080/api/proxy/download?url=https://example.com/file.zip" \
  -H "Range: bytes=1024-" \
  -o file.zip
```

## 前端集成

### JavaScript 示例

```javascript
// 完整下载
const response = await fetch('/api/proxy/download?url=' + encodeURIComponent(url));

// 断点续传
const response = await fetch('/api/proxy/download?url=' + encodeURIComponent(url), {
    headers: { 'Range': 'bytes=1024-' }
});

// 获取文件信息
const contentLength = response.headers.get('content-length');
const contentType = response.headers.get('content-type');
const contentRange = response.headers.get('content-range');
```

## 配置属性

```yaml
streaming:
  download:
    enabled: true                    # 是否启用
    buffer-size: 8192                # 缓冲区大小（字节）
    connect-timeout: 10000           # 连接超时（毫秒）
    read-timeout: 60000              # 读取超时（毫秒）
    max-file-size: -1                # 最大文件大小（-1 不限制）
    allowed-domains: []              # 域名白名单
    allow-all-domains: false         # 允许所有域名（危险）
```
