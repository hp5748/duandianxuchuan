# 默认下载目录功能设计

## 需求背景
用户希望无需每次下载都选择保存位置，能够自动保存到预设的下载目录。

## 技术方案

### 存储设计
| 数据 | 存储位置 | Key | 说明 |
|------|----------|-----|------|
| 下载历史记录 | localStorage | `download_history` | JSON 字符串 |
| FileHandle | IndexedDB | record.id | 文件句柄 |
| DirectoryHandle | IndexedDB | `default_download_dir` | 目录句柄 |

### API 使用
```javascript
// 选择目录
const dirHandle = await window.showDirectoryPicker();

// 保存到 IndexedDB（与 FileHandle 使用同一个 store）
await db.put(dirHandle, 'default_download_dir');

// 从目录创建文件
const fileHandle = await dirHandle.getFileHandle(fileName, { create: true });

// 权限检查
const permission = await dirHandle.queryPermission({ mode: 'readwrite' });
if (permission !== 'granted') {
    await dirHandle.requestPermission({ mode: 'readwrite' });
}
```

### 下载流程变更

```
原流程：
start() → showSaveFilePicker() → download()

新流程：
start() → 检查默认目录
              ├─ 已设置且有权限 → dirHandle.getFileHandle() → download()
              ├─ 已设置但无权限 → requestPermission() → download()
              └─ 未设置 → showSaveFilePicker() → download() [原有流程]
```

### UI 变更

1. **新增区域**：在 URL 输入框上方添加"下载设置"区域
   - 显示当前默认目录状态
   - "设置目录"按钮
   - "清除目录"按钮

2. **状态显示**：
   - 未设置：「📁 未设置默认目录」
   - 已设置：「📁 下载到: [目录名]」

3. **浏览器兼容性**：
   - 不支持 showDirectoryPicker() 时隐藏此功能

### 权限处理

1. **权限失效场景**：
   - 浏览器重启后
   - 长时间未使用
   - 用户手动撤销

2. **处理策略**：
   - 每次下载前调用 `queryPermission()` 检查
   - 权限不足时调用 `requestPermission()` 重新请求
   - 请求失败时降级到 `showSaveFilePicker()`

### 代码修改点

1. **DownloadHistory 类**
   - 新增 `getDirectoryHandle()` 方法
   - 新增 `saveDirectoryHandle()` 方法
   - 新增 `removeDirectoryHandle()` 方法

2. **DownloadManager 类**
   - 新增 `defaultDirHandle` 属性
   - 新增 `loadDefaultDirectory()` 方法
   - 新增 `setDefaultDirectory()` 方法
   - 新增 `clearDefaultDirectory()` 方法
   - 新增 `checkDirectoryPermission()` 方法
   - 修改 `start()` 方法：优先使用默认目录

3. **UI**
   - 新增下载设置区域 HTML
   - 新增相关 CSS 样式
   - 绑定按钮事件

### 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| 目录不存在（用户删除） | 提示重新选择 |
| 权限被拒绝 | 降级到 showSaveFilePicker |
| 浏览器不支持 | 隐藏此功能，使用原有流程 |
