# 架构设计

## 项目概述

streaming-download 是一个支持大文件流式代理下载的 Spring Boot Starter 组件，核心特性是 O(1) 内存占用和断点续传支持。

## 模块结构

```
streaming-download/
├── streaming-download-core/              # 核心模块（无 Spring 依赖）
├── streaming-download-spring-boot-starter/  # Starter 自动配置
├── streaming-download-demo/              # 演示应用
└── pom.xml                               # 父 POM
```

## 各模块职责

### 1. streaming-download-core

**职责**：提供核心下载能力，无 Spring 依赖，可被任何 Java 项目使用。

**核心类**：

| 类名 | 职责 |
|------|------|
| `RangeRequest` | 解析 HTTP Range 请求头 |
| `RangeResponse` | 封装 Range 响应信息 |
| `FileInfo` | 文件元信息封装 |
| `StreamingDownloader` | 远程文件下载器，O(1) 内存流式传输 |
| `LocalFileDownloader` | 本地文件下载器，支持本地路径和 UNC 路径 |
| `UnifiedDownloader` | 统一下载器，自动路由到远程或本地下载器 |
| `PathTypeDetector` | 路径类型检测（HTTP/本地/UNC） |
| `UrlValidator` | URL 安全校验（白名单、SSRF 防护） |

**异常体系**：

| 异常类 | HTTP 状态码 | 说明 |
|--------|-------------|------|
| `InvalidUrlException` | 400 | URL 格式非法 |
| `InvalidPathException` | 400 | 本地路径格式非法 |
| `DomainNotAllowedException` | 403 | 域名不在白名单 |
| `LocalFileNotFoundException` | 404 | 本地文件不存在 |
| `FileTooLargeException` | 413 | 文件过大 |
| `RangeNotSatisfiableException` | 416 | Range 无效 |
| `UpstreamException` | 502 | 上游服务器错误 |

### 2. streaming-download-spring-boot-starter

**职责**：Spring Boot 自动配置，开箱即用。

**核心类**：

| 类名 | 职责 |
|------|------|
| `StreamingDownloadProperties` | 配置属性绑定 |
| `StreamingDownloadAutoConfiguration` | 自动配置类 |
| `ProxyDownloadController` | REST 控制器 |

**API 端点**：

- `GET /api/proxy/download?url=xxx` - 流式代理下载

### 3. streaming-download-demo

**职责**：演示应用，验证 Starter 集成。

**配置**：
- 端口：8080
- 测试页面：`/download.html`

## 数据流

```
前端 → ProxyDownloadController → PathTypeDetector
                                      ↓
                        ┌─────────────┴─────────────┐
                        ↓                           ↓
                  isRemote=true              isRemote=false
                        ↓                           ↓
                  UrlValidator           (跳过安全校验)
                        ↓                           ↓
                        └─────────────┬─────────────┘
                                      ↓
                              UnifiedDownloader
                                      ↓
                        ┌─────────────┴─────────────┐
                        ↓                           ↓
               StreamingDownloader          LocalFileDownloader
                        ↓                           ↓
                  目标服务器                   本地文件/UNC
                                      ↓
                                 HttpServletResponse (流式输出)
```

## 关键设计决策

### 1. O(1) 内存占用

使用固定大小 buffer（默认 8KB）进行流拷贝：

```java
byte[] buffer = new byte[bufferSize];
while ((bytesRead = input.read(buffer)) != -1) {
    output.write(buffer, 0, bytesRead);
}
```

### 2. 断点续传

- 后端支持 HTTP Range 请求
- 前端使用 File System Access API 记录已下载位置
- 暂停时保留 `loadedBytes`，继续时发送 Range 请求

### 3. 安全防护

- **域名白名单**：仅允许配置的域名
- **SSRF 防护**：禁止访问内网 IP
- **文件大小限制**：可配置最大文件大小

## 依赖关系

```
core (无外部依赖) ← starter (依赖 Spring Boot) ← demo
```
