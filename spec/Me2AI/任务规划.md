## 优先级

| 优先级 | 模块 | 说明 |
|--------|------|------|
| P0 | 核心模块 | 其他模块的基础 |
| P0 | Starter 模块 | 核心功能入口 |
| P1 | 前端页面 | 演示和测试必需 |
| P1 | Demo 应用 | 集成测试必需 |
| P2 | 文档完善 | 可后续迭代 |

## 依赖关系

```
core → starter → demo
       ↑
    前端页面（静态资源）
```

- 核心模块独立，无 Spring 依赖
- Starter 模块依赖核心模块
- Demo 应用依赖 Starter 模块
- 前端页面作为 Starter 的静态资源
