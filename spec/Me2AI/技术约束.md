# 技术约束

## 技术栈

| 层级 | 技术选型 | 版本 |
|------|----------|------|
| JDK | Oracle/OpenJDK | 8+ |
| 后端框架 | Spring Boot | 2.7.6 |
| 构建工具 | Maven | 3.6+ |
| 前端 | 原生 HTML/JS/CSS | - |
| 浏览器 API | File System Access API | Chrome 86+ |

## 架构决策

### 模块划分
采用多模块结构，职责分离：

```
streaming-download/
├── streaming-download-core/              # 核心模块（无 Spring 依赖）
├── streaming-download-spring-boot-starter/  # Starter 自动配置
├── streaming-download-demo/              # 演示应用
└── pom.xml                               # 父 POM
```

### 设计原则
1. **O(1) 内存占用**：使用固定大小 buffer（默认 8KB）进行流拷贝
2. **零缓存**：严禁将文件全量或大块装入内存
3. **职责分离**：核心模块不依赖 Spring，可被非 Spring 项目复用
4. **配置化**：所有参数均可通过配置文件调整

### 断点续传策略
- **纯前端记录**：后端仅支持 Range 请求，前端记录已下载位置
- **无服务端缓存**：后端不存储临时文件
- **浏览器兼容**：依赖 File System Access API（Chrome 86+）

## 非功能性需求

### 性能要求
| 指标 | 要求 |
|------|------|
| 内存占用 | 常数级 O(1)，约 8KB buffer |
| 下载速度 | 与直接下载相当，无额外性能损耗 |
| 并发能力 | 支持多用户同时下载 |

### 安全要求
| 指标 | 要求 |
|------|------|
| URL 校验 | 可配置白名单域名 |
| 文件大小限制 | 可配置最大下载文件大小 |
| 超时控制 | 防止长时间占用连接 |

### 可用性要求
| 指标 | 要求 |
|------|------|
| 浏览器兼容 | Chrome 86+（File System Access API） |
| 集成方式 | Spring Boot Starter，引入依赖即可 |
| 文档完整 | 提供完整的 API 文档和集成示例 |

## 技术限制

### 必须遵守
1. **严禁**返回 `byte[]`、使用 `ResponseEntity<byte[]>` 或任何将流缓存到内存的操作
2. **严禁**前端拼接 Blob，必须读一块写一块
3. **必须**透传 Content-Length，这是前端计算进度的依据
4. **必须**使用 try-with-resources 确保流正确关闭

### 配置项
```yaml
streaming:
  download:
    buffer-size: 8192        # 缓冲区大小（字节）
    connect-timeout: 10000   # 连接超时（毫秒）
    read-timeout: 60000      # 读取超时（毫秒）
    max-file-size: -1        # 最大文件大小（-1 不限制）
    enabled: true            # 是否启用
```
